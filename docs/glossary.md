# Glossary (D-194)

English terms for the project's Slovak domain words. Use them in code, comments, docs and D-records.
The source is the English plan copy (AIMforked `docs/platform/plan.md`, rev 115). UI labels stay Slovak;
when a text names a UI label, give the English first and the Slovak label in parentheses once,
e.g. Take over ("Prevziať").
