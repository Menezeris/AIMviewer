# DECISIONS.md - pointer

The decision records moved to one file per record (D-197, lean docs):

- Index (number, title, status, one line): [`decisions/README.md`](decisions/README.md)
- A record: `decisions/D-nnn.md` (for example [`decisions/D-044.md`](decisions/D-044.md))
- Section headings and intro text of the old file: [`decisions/sections.md`](decisions/sections.md)

New record: create `decisions/D-nnn.md` and add one row to the index. Do not append to this file.
